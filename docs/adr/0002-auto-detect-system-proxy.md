# 浏览器自动探测并继承系统代理

插件启动浏览器时自动探测系统代理，并把探测结果传给 Playwright 的 launch：优先级为显式 `proxy` 配置 → `HTTP(S)_PROXY`/`ALL_PROXY` 环境变量 → Windows 系统代理（注册表）。

理由：Playwright 的 bundled Chromium 默认直连、不继承系统代理；用户本机浏览器走系统代理（如 `127.0.0.1:7897`）能上外网，而插件直连打不开外网。自动继承让「用户能上什么，插件就能上什么」，无需用户知道自己的代理地址。

代理默认 bypass 本地回环地址（`<local>,localhost,127.0.0.1,::1`），避免把本地服务/测试 fixture 也走代理。

考虑过的替代：要求用户手动在 cordis.patch.yml 配 `proxy`——可用但默认对用户不透明，且大多数用户不知道自己的代理地址；仅靠环境变量——Windows 图形界面用户通常不设环境变量代理。
