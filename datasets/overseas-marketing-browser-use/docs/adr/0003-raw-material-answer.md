# ADR-0003：原始营销素材是核心 evidence

## 状态

Accepted

## 背景

“用户痛点”“购买动机”“品牌定位”等结论是对帖子、评论和搜索结果的二次分析。如果把这些结论作为 Browser Use 的答案，就无法判断插件是否真正采集了可核对的营销素材。

## 决策

Browser Use 的必需 evidence 停留在原始素材层：逐字英文片段、帖子、评论、SERP 条目、页面片段、URL、页面元数据和必要的图片证据。营销分析可以由后续人员或模型完成，但不能替代原始素材。最终响应可以按照题目和响应 schema 对这些 evidence 做固定筛选、计数、去重或比例计算，但不能生成开放式结论。

## 结果

每条抽象判断都可以回溯到具体来源，但原始采集任务本身不要求生成抽象判断。
