# ADR-0006：按操作复杂度编排 task group

## 状态

Superseded by ADR-0008

## 背景

按产品主题拆成 10 个独立题目会重复相同的 Browser Use 流程：搜索、识别结果、打开详情、读取评论或摘录页面。主题不同并不代表操作难度不同，也不利于比较 agent 在复杂度递进下的表现。

## 决策

本决策适用于 v0.2-v0.3。v0.4 起不再增加 task group 层；10 道题分别独立执行和评分，每个平台各用 L1 至 L5 标注操作复杂度。

## 取舍

- 保留复杂度梯度，同时删除 `task_id`、`subtask_id`、`case_id` 三层标识造成的额外概念。
