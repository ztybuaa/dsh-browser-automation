# 案例选择与可行性验证方法

## 目的

在正式冻结案例前，验证候选题目是否同时满足营销价值、原始素材可得性和固定边界要求。这里的验证属于设计阶段，不是 Browser Use 正式测评。

## 选择流程

1. 从真实营销问题出发，提出一个候选研究对象和素材用途。
2. 用公开网页进行探索性检索，观察目标主题的素材密度、来源多样性和页面可访问性。
3. 检查候选题目是否可以固定品牌/产品/品类、平台区域、查询词、时间区间、来源集合和素材数量。
4. 检查原始素材是否能直接服务营销分析，而不是只能靠抽象推理产生价值。
5. 检查是否依赖视频内容理解；如果依赖，则淘汰或重写主题。
6. 如果候选主题不适合，允许在设计期进行 fallback，重新验证新的固定对象。
7. 通过检查后冻结案例规格。冻结后不允许执行期 fallback。

## 通过标准

- 一个明确的核心营销研究问题。
- 一个固定、可描述的研究对象。
- 固定的平台和操作区域。
- 固定的查询词集合和时间范围。
- 预先确定的原始素材类型、必采数量、上限和字段。
- 能够保存英文原文、来源元数据和必要的图片证据。
- 不需要运行时换对象或换主题才能完成。

## 记录要求

研究记录应区分：候选对象、尝试过的查询、发现的素材类型、淘汰原因、fallback 决策和最终冻结对象。候选探索记录不进入 Browser Use 执行 prompt。
